# PCInfo — инструкции для Claude Code

## О проекте

PCInfo — небольшое Windows-приложение для получения информации о компьютерах в домене.

Основной исходный код находится в:

* `PCinfo.ps1` — основной PowerShell-скрипт.
* `PCinfo.exe` — скомпилированная версия приложения. Файл не хранится в Git и исключён через `.gitignore`.

Приложение работает со сквозной авторизацией: при запуске пользователь вводит логин и пароль своей доменной учётной записи. После авторизации пользователь может искать доменные компьютеры по имени хоста или IP-адресу и получать информацию о них.
